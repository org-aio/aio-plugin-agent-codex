# 原始 Codex Renderer 的设备桥接

连接设备本机的 loopback CDP，通过官方 `open-in-new-window` 创建独立窗口上下文，只替换该窗口的入口文档；原始 preload、App Host、IPC 与 worker 接口保持由 Codex 提供。现有桌面窗口不复用 App View 端口。

原生新窗口接口会显示并聚焦辅助窗口。连接完成后通过官方 `open-current-main-window` 恢复现有桌面主窗口，不改变其当前会话；辅助窗口显示用途和返回桌面按钮，可以最小化，关闭时只断开对应网页。当前 Renderer 接口不提供隐藏原生窗口的能力，因此不声称辅助窗口已完全隐藏，也不依赖额外的系统辅助功能权限。

设备只接受共享协议定义的消息和方法，不接收 JavaScript 或 CDP 命令。原始前端和 Buddy 资源在用户安装目录读取，不放进 AIO 发布包。协议保持 structured clone 的数组、循环引用、二进制、Map、Set 和 BigInt。

网页文档额外加载桥接层自带的 `__mobile.css`，仅在 700px 以下重排原生输入操作、扩大触控区域并限制弹窗边界。侧栏覆盖主区，输入区排在恢复列表之前；历史会话底部工具区域限高并独立滚动。矮屏收起欢迎装饰，项目切换仍在原版工具栏中。桌面原文件和窗口不受此样式影响。样式依赖原版 `data-composer-*`、`data-app-shell-*`、`data-thread-find-composer` 语义属性、首页 `group/home-composer-layout` 布局容器和 Buddy 的 `data-codexhost-*` 标记，当前实际核对版本为 26.1007.21159，升级后仍需移动端兼容验收。设备选择栏在手机连接成功后收起，展开不会重建视图。两层文档保留浏览器缩放并声明可缩放视口，不更改原生通信的 Electron 能力声明。

外层设备栏随网页插件发布，内层兼容样式随设备使用的 `@zjarlin/aio-codex-web` 发布。只更新网页不能替换旧设备中的内层样式。浏览器窄屏和短视口验收不代替 iOS/Android 真机软键盘验收。

每个连接拥有自己创建的 target，关闭只清理该 target。完整插件上线仍需设备身份与撤权、真实网页交互和升级兼容验收。

文件上传由设备端 Node 连接管理，不向官方 preload 添加虚构方法。固定上传帧只接受文件名、声明大小和顺序分块，不能指定目标目录或任意路径。文件以独立目录和文件权限写入系统临时目录，收到完整写入确认后才返回设备路径。未完成的文件在取消或连接关闭时删除；已交付文件继续供任务和审批使用，由设备的系统临时目录管理其后续保留。

目录传输先建立设备生成的私有根目录，只接收经过校验的相对目录项与文件分块。拒绝绝对路径、回退路径、反斜杠、保留名称、路径冲突及超限数据；隐式父目录也计入 4096 项配额。只有全部子文件完成后才返回根路径；取消目录会删除已完成和部分子文件并释放大小配额。完整交付的目录在连接关闭后继续保留。每视图 512 MiB、单文件 128 MiB，相对路径最多 32 层，最多 8 个文件/目录根同时传输。
